1. Logical Heading Hierarchy (H1 through H3)

Search engines rely on headings to build an outline of your web page. A document should only ever contain a single <h1> element representing the main title, followed by properly nested <h2> sub-sections and <h3> sub-topics.

Sub-Topic: Heading Nesting Rulebook

Never skip levels (e.g., jumping from H1 directly to H3). Skipping levels breaks the semantic accessibility tree for screen readers and dilutes search index entity relations.

2. Accessible & Performant Image Assets

For optimal SEO, images must contain meaningful, descriptive alt text, explicit width and height attributes to prevent Cumulative Layout Shifts (CLS), and modern lazy loading parameters.

3. Descriptive Anchor Text & Link Equity

Avoid non-descriptive links like "click here" or "read more". Instead, embed contextual keyword phrases into your internal links. Learn more in our detailed resource on internal link optimization strategies .

/**
 * Builds an automated Table of Contents based on valid page H2 tags.
 */
function generateTableOfContents() {
    const tocList = document.getElementById('toc-list');
    const headings = document.querySelectorAll('main article h2');

    if (!tocList || headings.length === 0) return;

    headings.forEach((heading, index) => {
        // Ensure each heading has an ID for fragment linking
        if (!heading.id) {
            heading.id = `section-heading-${index + 1}`;
        }

        const listItem = document.createElement('li');
        const link = document.createElement('a');
        
        link.href = `#${heading.id}`;
        link.textContent = heading.textContent;
        link.className = "toc-link";

        listItem.appendChild(link);
        tocList.appendChild(listItem);
    });
}

Technical SEO Audit & Criteria Compliance

Reference table detailing every essential factor required for modern Google Search indexing.

1. Head & Meta Tags
  • <!DOCTYPE html> declaration
  • lang="en" attribute on HTML tag
  • UTF-8 Charset & Viewport Meta
  • Canonical Tag matching exact URL
2. Semantic Hierarchy
  • Exactly ONE <h1> per document
  • Sequential <h2> and <h3> order
  • Layout tags: header, main, article, footer
3. Structured Data & Social
  • Schema.org JSON-LD TechArticle block
  • Open Graph protocol tags (og:title, etc.)
  • Twitter Card meta parameters
4. Media & Performance
  • Descriptive alt attributes on images
  • Explicit width/height to prevent layout shifts
  • loading="lazy" native browser optimization
5. Navigation & Links
  • Schema BreadcrumbList Markup
  • Keyword-rich descriptive link anchor text
  • Dynamic Table of Contents (TOC) links
6. Accessibility & Vitals
  • ARIA landmark labels (aria-label)
  • Contrast-compliant color palettes
  • Mobile-first fluid layout scaling
